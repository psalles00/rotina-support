Confidentialité

Vos données

Les routines, les étapes et la progression sont enregistrées sur votre appareil. Lorsque iCloud est disponible, ces données sont synchronisées de façon privée entre vos appareils, quelle que soit votre offre. Les préférences d’apparence restent sur cet appareil.

Calendrier et alarmes

L'accès au Calendrier n'est demandé que lorsque vous activez l'intégration. Le Rotina lit uniquement les calendriers sélectionnés pour afficher les événements et utilise le AlarmKit et les notifications locales pour les rappels configurés par vous.

Achat

Les abonnements sont traités par App Store. Le Rotina consulte uniquement l'état de l'achat nécessaire pour libérer les ressources Premium.

Conservation et suppression

Vous pouvez supprimer vos routines et leurs enregistrements dans l’app. Les données locales restent jusqu’à leur suppression ou à la désinstallation de l’app. Les données synchronisées peuvent rester dans iCloud ; gérez le stockage de Rotina dans les réglages de votre compte Apple.

Rotina conserve une copie locale des événements affichés tant que l’intégration est active. La désactivation de l’intégration ou le retrait de l’autorisation efface ce cache sans supprimer les événements du Calendrier. Vous pouvez retirer les autorisations dans les Réglages de l’appareil.

Assistance

Lorsque vous envoyez un e-mail d’assistance, vous choisissez les informations à partager. Votre app de messagerie envoie le message à pedrosalles00@gmail.com. Vous pouvez aussi adresser vos demandes concernant la confidentialité à cette adresse.
